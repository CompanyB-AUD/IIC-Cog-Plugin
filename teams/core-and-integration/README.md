## First session

1. Read the shared guides and your role guide.
2. Choose an issue, individual assignee and reviewer.
3. Fetch the current team branch and create an issue branch from it.
4. Use the existing shared scaffold, or the agreed contract and labeled mocks while Core builds it; do not generate an independent application.
5. Open a focused PR into `team/core-and-integration` with acceptance evidence.

This README is part of the common repository baseline. All teams can see the other teams' guides, but each follows its own ownership. The root AGENTS.md and dev.md stay identical at branch creation and are maintained through main.
