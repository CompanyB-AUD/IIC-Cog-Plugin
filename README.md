The current scope prioritizes reading mode, distraction reduction, configurable presentation, guided reading, chunking and progress. Existing-caption support, transcripts, visual alerts and opt-in AI are planned **Should** features; stretch **Could** items are unscheduled.

This repository currently contains planning material. Installation instructions and release artifacts will be added with the implementation; the backlog is not evidence that features already work.

## Schedule
Five weekly sprints run from 13 November to 17 December 2026. Final presentation: **18 December 2026**, 20 minutes plus 10 minutes Q&A. Times and dates use Africa/Accra.

## Collaboration
Company A and Company B must agree the shared toolbar, module API, preferences and demo environment. Existing documents are proposals until approval is recorded. Team members select assignees and estimates in planning; do not infer ownership from epic labels.
